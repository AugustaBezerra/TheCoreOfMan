# The Core of Man • A Era dos Céus Partidos 📖✨

> Experiência web imersiva e cinematográfica para o sistema de RPG autoral **"The Core of Man - A Era dos Céus Partidos"**, desenvolvido por **Augusta Bezerra**.

---

## 🌌 Sobre o Projeto

O site transporta o jogador diretamente para o mundo de Core:
1. **O Grimório no Pedestal:** A experiência se inicia diante do antigo livro fechado sobre o pedestal de bronze e pedra ancestral, pulsando com runas arcanas e o selo cósmico.
2. **O Mergulho Dimensional (Powered by Remotion):** Ao clicar em **"LEIA-ME"**, o selo se rompe, as páginas levitam e uma coluna de luz etérea suga a câmera para dentro do grimório em uma transição cinematográfica.
3. **O Universo dos Céus Partidos:** O jogador emerge dentro do cosmos profundo, com visão para cidades flutuantes, anéis astronômicos e o **Códice do Navegante**, contendo os 10 capítulos com as regras, status vitais, combate tático e o compêndio integral de **Dons do Cerne** (com todos os níveis 0 a 5) e **Fardos do Verbo** (com todas as cepas e consequências).

---

## 🛠️ Tecnologias Utilizadas

- **[React 18](https://react.dev/)** + **[TypeScript](https://www.typescriptlang.org/)**
- **[Remotion](https://www.remotion.dev/)** (`remotion` & `@remotion/player`) para interpolação cinematográfica de frames
- **[Vite](https://vitejs.dev/)** para compilação ultrarrápida
- **[Tailwind CSS](https://tailwindcss.com/)** para estilização temática
- **[Lucide React](https://lucide.dev/)** para ícones celestiais e astronômicos
- **Web Audio API** sintetizada proceduralmente para ambiência e virada de folhas
- **Canvas 2D** para partículas de poeira cósmica reativas ao mouse

## 🚀 Como Rodar Localmente

```bash
# 1. Instalar as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build

# 4. Pré-visualizar o build
npm run preview
```
